# Entrega de Videoteca para un piloto pequeño

Fecha: 16 de septiembre de 2026.

Empiece por INICIO.html. El manual completo tiene índice navegable e impresión, instalación desde cero, proveedores, menú completo, ejemplos de empleados y familia y plan para ensayar todas las áreas. La referencia técnica incluye 675 funciones del servidor, 138 del HTML y 52 rutas API, con firmas y enlaces a la fuente íntegra.

## Archivos de instalación

- instalacion/Codigo.gs: copia exacta de Codigo_21_Seguridad_Cola.gs.
- instalacion/Index.html: copia exacta de Index_7_Guardado_Seguro.html.
- instalacion/appsscript.base.json: plantilla opcional para un proyecto NUEVO, con V8, Bogotá y servicio YouTube v3. No representa los ajustes actuales de producción.

La versión interna nueva es v2026.6.37-VIDEOTECA-PILOTO-R4. La versión 8 de Google documentada antes corresponde a Código 19 e Index 5. Esta revisión se preparó y probó localmente; todavía debe publicarse siguiendo el capítulo 23. No se alteraron credenciales, activadores o datos reales.

## Para quién es cada archivo

El administrador conserva el paquete completo. Puede compartir manuales/Guia_participantes.html con el grupo. La carpeta ejemplo_administrador contiene RESPUESTAS de examen y no se distribuye a participantes antes de evaluar. El TSV es una ayuda de carga en una copia nueva, no un importador automático; se entrega en BORRADOR para revisión.

## Antes de invitar personas

Prepare tres a cinco adultos, accesos individuales, un módulo validado y un respaldo actualizado. Pruebe un recorrido completo y la separación de resultados entre dos participantes. No haga públicas las hojas del libro para abrir el portal.

No se recortaron funciones para el piloto. El manual y la referencia incluyen todo el código y señalan los requisitos pendientes de búsqueda semántica, Ollama remoto, APIs familiares y certificados. Hay 122 pruebas locales aprobadas: 83 regresiones previas, 18 de interfaz, 6 del panel y 15 de R4. Usan servicios simulados y no sustituyen el ensayo real del grupo.

Este paquete no contiene claves, propiedades de producción ni copias de datos personales. No reemplaza el respaldo cifrado completo. SHA256SUMS.txt permite cotejar los archivos de entrega.

La revisión R4 de cola y examen se explica en CAMBIOS_R4 y el capítulo 24. Una tarea EN_PROCESO interrumpida exige comprobar su resultado antes de repetirla.
